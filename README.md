# Live Studio

Build the foundation of a professional multi-camera live streaming and video production web application using React, TypeScript, Tailwind CSS, and Supabase.

Create a modern, responsive interface with a professional dark broadcast-studio design.

Implement the following pages:

Landing page

Sign up and login

User dashboard

Production sessions

Camera connection page

Live production studio

Livestream management

Recordings library

Account settings

Implement Supabase authentication, database schemas, user profiles, production sessions, and recording metadata.

Allow users to create, rename, open, and delete production sessions. Each session should have a unique identifier and an owner.

Build reusable components for camera tiles, video monitors, production controls, status indicators, dialogs, and notifications.

Use real Supabase data for implemented functionality. Do not use fake buttons or claim features work when they are not implemented.

Do not implement the complete video infrastructure in this phase. Establish a clean, modular architecture that supports real-time camera transport, video composition, recording, and live streaming in subsequent phases.
